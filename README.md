# Red Zone Frames

Red Zone Frames is an NFL player frame e-commerce site, built a project for COMP 3340.

## Live Site

http://morrah.myweb.cs.uwindsor.ca/redzoneframes/

## What This Project Includes

- A full public storefront where you can browse a 20-player catalog (current roster and retro legends), a fully custom "Design Your Own" frame builder, a shopping cart, and checkout
- Customer accounts with registration, login, order history, and product reviews
- A 5-page help wiki for customers, including embedded video walkthroughs
- A complete admin panel that allows you to manage products, orders, users, player requests, and switching between 3 site themes
- A backend status monitoring page
- A MySQL database with tables
- PHP 
- MySQL
- HTML5, CSS3, JavaScript
- Chart.js for the admin dashboard's sales chart
